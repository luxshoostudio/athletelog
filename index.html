How auto-sync works

Garmin has no public API a browser can call, so a relay writes athletelog-garmin.json into your GitHub Gist and this app reads it. Set up either relay once — the Mac garmin_sync.py LaunchAgent, or an iOS Shortcuts automation that posts Active Energy from Apple Health. Uses the same token as Gist backup.
